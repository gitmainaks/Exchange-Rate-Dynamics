# 🪙 Exchange Rate Dynamics — A Time Series Study

This repository explores the dynamics of the INR/USD exchange rate using time series econometric models, along with an analysis of India's major trade partners.

## 📊 Overview

- **Model-1 (VAR):** Vector Autoregression model built in Python to study the interdependencies driving INR/USD exchange rate movements.
- **Model-2 (ARDL):** Autoregressive Distributed Lag model for examining short- and long-run relationships among the relevant variables.
- **VAR Model (using EViews):** A parallel VAR implementation in EViews for cross-validation of results.
- **India's Major Trade Partners:** Supporting data analysis (notebook, spreadsheet, and report) on India's key trading partners, providing context for the exchange rate study.

## 🛠️ Tools & Methods

- Python (Jupyter Notebooks)
- EViews
- Vector Autoregression (VAR)
- Autoregressive Distributed Lag (ARDL)
